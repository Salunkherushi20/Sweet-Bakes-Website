# Sweet Bakes Website

A responsive, modern bakery website for cakes, pastries, cupcakes and custom celebration cake enquiries.

## Design
- Cream, peach-pink and chocolate-brown palette
- Mobile-friendly navigation and layouts
- Cake-focused product cards and custom cake enquiry modal
- Accessible form labels, keyboard Escape-to-close, and reduced-motion support

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for GitHub Pages to publish. The expected site URL is `https://salunkherushi20.github.io/Sweet-Bakes-Website/` once deployment succeeds.

## Important launch notes
- The enquiry form currently runs only in the browser and prepares copyable text. It does **not** send, store or transmit enquiries. Connect it to a real, secure endpoint before accepting orders.
- No business phone, email, address or verified prices are included. Add verified business details before launch.
- Product photography is loaded from Unsplash URLs and requires internet access.
- This repository is a static frontend; do not put private keys, passwords or customer data in the source.
